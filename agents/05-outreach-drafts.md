# Outreach-draft agent

## Input

A quality-ready `ValueBrief` and a contact channel permitted by `TrialProfile`.

## Work

Create concise email and LinkedIn-message drafts that lead with a verified useful finding and invite the user to see the report or take a specific ZenABM action.

## Output

One or more `OutreachDraft` objects marked `draft`.

## Rules

- Never send, schedule, or impersonate a user.
- Do not use a contact channel without an allowed status from trial intake.
- Do not add performance claims that are absent from the value brief.
